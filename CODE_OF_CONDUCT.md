# Kithwork Code of Conduct

Kithwork should be a place where people can discuss code without dealing with harassment, ego contests, or personal attacks.

## What I expect

- Be direct about the work and respectful toward the person doing it.
- Critique code, decisions, and documentation with enough context to be useful.
- Give people room to ask basic questions and correct mistakes.
- Respect privacy. Never post somebody else's personal information or credentials.
- Stop when a maintainer asks a conversation to cool down or move on.

Harassment, discrimination, threats, sexual attention, doxxing, spam, and deliberately disruptive behavior are not accepted here.

## Where this applies

These rules apply in Kithwork issues, pull requests, discussions, release comments, and any public space where somebody is representing the project.

## Reporting a problem

If a report contains private or sensitive details, don't post those details in a public issue. Contact me through one of the profiles linked in the README, mention the Kithwork Code of Conduct, and share only what is needed to understand the situation.

For an ordinary public disagreement, open an issue with the smallest useful amount of context.

## Enforcement

I will review the available context and respond in proportion to the behavior. That can mean a private correction, removal of content, a temporary restriction, or a permanent ban from project spaces. Repeated behavior will be treated more seriously.

Maintainer decisions about project spaces are final.
